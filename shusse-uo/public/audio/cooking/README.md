# 調理シーン用 実録SE

Step 1「空中居合い斬り」プロトタイプはこのフォルダの **MP3 / WAV ファイル** を
AudioContext で読み込んで再生します。
**Web Audio API による合成音にはフォールバックしません**（既存 `src/lib/audio.ts` とは別系統）。
ファイル不在時は単に無音になります。

## 必要ファイル（Step 1 用）

| ファイル名     | 用途                           | 推奨尺・特徴                                   |
| -------------- | ------------------------------ | ---------------------------------------------- |
| `whoosh.mp3`   | 魚が空中を飛ぶ風切り音         | 0.6 ~ 1.2 秒。中域〜高域の風切り、減衰        |
| `slash.mp3`    | 居合い斬きの瞬間（鋭い金属感） | 0.3 ~ 0.6 秒。アタック強・余韻短              |
| `landing.mp3`  | 切り身がまな板に落ちる「パシッ」 | 0.2 ~ 0.4 秒。低域＋木質のアタック             |

## 推奨入手元

商用利用可ライセンスを確認の上ご利用ください。

- **Freesound.org** (CC0 / CC-BY): "sword slash", "whoosh", "meat slap", "wet thud"
- **Zapsplat**: 無料アカウントでDL可（クレジット表記）
- **効果音ラボ** (https://soundeffect-lab.info/): 日本語、商用OKの作品多数
- **Pixabay Audio**: ロイヤリティフリー

## ファイル仕様の目安

- フォーマット: MP3 / WAV（iOS/AndroidともAudioContext.decodeAudioData対応）
- ビットレート: MP3 192kbps 程度で十分
- ノーマライズ: -3 dB ピーク以下に抑え、再生時 volume パラメータでバランス調整
- 1ファイル 50KB 以下が理想（プロトタイプの起動レイテンシ最小化）
