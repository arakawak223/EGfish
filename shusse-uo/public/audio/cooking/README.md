# 調理シーン用 実録SE

Step 1「空中居合い斬り」/ Step 2「高速まな板カット」プロトタイプはこのフォルダの
**MP3 / WAV ファイル** を AudioContext で読み込んで再生します。
**Web Audio API による合成音にはフォールバックしません**（既存 `src/lib/audio.ts` とは別系統）。
ファイル不在時は単に無音になります。

## 必要ファイル（Step 1 用 = `/cook-prototype`）

| ファイル名     | 用途                           | 推奨尺・特徴                                   |
| -------------- | ------------------------------ | ---------------------------------------------- |
| `whoosh.mp3`   | 魚が空中を飛ぶ風切り音         | 0.6 ~ 1.2 秒。中域〜高域の風切り、減衰        |
| `slash.mp3`    | 居合い斬きの瞬間（鋭い金属感） | 0.3 ~ 0.6 秒。アタック強・余韻短              |
| `landing.mp3`  | 切り身がまな板に落ちる「パシッ」 | 0.2 ~ 0.4 秒。低域＋木質のアタック             |

## 必要ファイル（Step 2 用 = `/cook-prototype-2`）

| ファイル名   | 用途                                 | 推奨尺・特徴                                              |
| ------------ | ------------------------------------ | --------------------------------------------------------- |
| `chop.mp3`   | まな板に包丁が当たる「トン」         | 0.10 ~ 0.20 秒。アタック鋭く・余韻ほぼなし。連打前提でループ感が出ない単発音 |
| `clap.mp3`   | 最終タップのアクセント / 手粉「パンッ」 | 0.15 ~ 0.30 秒。中高域に張りがあり、止める音として聞こえること          |

実装は `chop.mp3` を 1 タップごとに `playbackRate` を 0.92 → 1.16 まで段階的に上げて再生し、
最終タップでは rate=1.18 で `chop.mp3` + `clap.mp3` を同時発火して「トトトトンッ！」を作ります。

## 推奨入手元

商用利用可ライセンスを確認の上ご利用ください。

- **Freesound.org** (CC0 / CC-BY): "sword slash", "whoosh", "meat slap", "wet thud"
- **Zapsplat**: 無料アカウントでDL可（クレジット表記）
- **効果音ラボ** (https://soundeffect-lab.info/): 日本語、商用OKの作品多数
- **Pixabay Audio**: ロイヤリティフリー

## ファイル仕様の目安

- フォーマット: MP3 / WAV（iOS/AndroidともAudioContext.decodeAudioData対応）
- ビットレート: MP3 192kbps 程度で十分
- ノーマライズ: -3 dB ピーク以下に抑え、再生時 volume パラメータでバランス調整
- 1ファイル 50KB 以下が理想（プロトタイプの起動レイテンシ最小化）

## 必要ファイル（Step 3 用 = `/cook-prototype-3`）

| ファイル名     | 用途                       | 推奨尺・特徴                                                  |
| -------------- | -------------------------- | ------------------------------------------------------------- |
| `nigiri.mp3`   | 握り「ギュッ」（押し込み） | 0.10 ~ 0.20 秒。柔らかい圧縮感（湿った布のキュッ／パフ系）。連打前提でループ感が出ない単発音 |
| `landing.mp3`  | ネタを置く瞬間（流用）     | Step 1 と共有                                                 |
| `clap.mp3`     | 3拍目の締めアクセント（流用） | Step 2 と共有                                                 |

実装は 3 タップそれぞれで `nigiri.mp3` を発火し、3 タップ目では `clap.mp3` を同時に重ねて
「ギュッ・ギュッ・ギュッ！」の締めを作ります。`landing.mp3` は完成時の「コトッ」に使います。
