# 調理シーン用 魚画像（実写プレースホルダ）

Step 1「空中居合い斬り」/ Step 2「高速まな板カット」プロトタイプはこのフォルダの
実写画像を読み込みます。
**手描き／合成画像にはフォールバックしません**。未配置の場合は画面に
「📷 画像未配置」の赤枠タイルが表示されます。

> Step 2 では同じ魚画像を「柵 (fillet)」として横長に表示し、`clip-path: inset()`
> で水平方向に切り出して切れ片を作ります。横長 (~1024×384) ならそのままで
> 切り口が綺麗に見えるはずです。

## 必要ファイル

以下の5枚を PNG（推奨: 透過背景）で配置してください。
ファイル名は `Species` キーと一致させること。

| ファイル名         | 種     | 推奨サイズ (横向き)    |
| ------------------ | ------ | ---------------------- |
| `buri.png`         | ブリ   | 横長 ~1024×384 程度    |
| `suzuki.png`       | スズキ | 横長 ~1024×384 程度    |
| `maiwashi.png`     | マイワシ | 横長 ~768×256 程度   |
| `sawara.png`       | サワラ | 横長 ~1024×384 程度    |
| `konoshiro.png`    | コノシロ | 横長 ~768×320 程度  |

## 推奨入手元

すべて商用利用可・改変可ライセンスを確認の上ご利用ください。

- **Wikimedia Commons**: 例) "Seriola quinqueradiata"（ブリ）など学名検索
- **Pixabay** (ピクサベイ): 「ブリ 魚」「鯖 魚」など日本語検索
- **Pexels** (ペクセルズ): "yellowtail fish" 等の英語検索
- **photoAC**（写真AC）: クレジット表記要件を確認の上で

## 加工指針（任意）

- 背景は透過（PNG）で抜くと clip-path 切断が綺麗に見えます
- 魚体は **頭が左 / 尾が右** 向きで揃えると挙動が一貫します
- 影は焼き込まずレイヤーで持つと、切断後の落下時に自然な影が描画されます
- 1枚 200KB 以下を目安に圧縮（実機ロード遅延を防ぐため）

## トラブル

- 配置しても赤枠が消えない: ブラウザのキャッシュリロード (Cmd/Ctrl+Shift+R)
- ロードはできているが歪む: `objectFit: "cover"` で表示しているため、
  魚体のアスペクト比が極端に縦長/横長だと潰れて見えることがあります
