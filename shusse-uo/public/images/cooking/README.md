# /public/images/cooking — リズム握り (案A) 用画像

`/cook-prototype-3` (RhythmNigiri.tsx) が読み込む画像を置く場所。
**未配置でも動作は壊れない** (CSS フォールバックでシャリ/ネタ風の見た目になる)。

## 配置するファイル

| パス | 用途 | 推奨サイズ | 備考 |
|---|---|---|---|
| `shari-top.png` | 空シャリ俯瞰 (ネタが乗る前) | 320×200 px / 透過PNG | 楕円俵型、影は画像に焼き込まずCSSで付与 |
| `nigiri-done.png` | 完成握り (シャリ+ネタ乗り) | 320×220 px / 透過PNG | press完了時に shari-top.png と差し替え |
| `fish/buri.png` | ネタ (現状ブリ固定) | 240×120 px / 透過PNG | 横長スライス、釣果と紐付ける場合は別ファイル |

## 仕様メモ

- 1枚あたり 200KB 以下推奨 (LCP/モバイル回線対策)
- 透過PNG必須 (背景の檜板グラデーションに重ねる)
- 俯瞰視点で揃える (横から見た写真は使えない)
- ネタは将来的に釣果連動で動的に切替予定 (今は buri.png 固定)
